# Photo Gallery Images

Upload your real wedding photos to this directory.

Ensure the filenames match those referenced in the `photos.js` configuration file in the repository root. Currently, those filenames are:
- `ring.jpg`
- `dress.jpg`
- `cake.jpg`
- `couple-walking.jpg`
- `table.jpg`
- `couple-nature.jpg`
- `kiss.jpg`
- `holding-hands.jpg`
